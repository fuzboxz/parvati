# Known firmware divergences (tests/firmware_parity_test).
#
# One entry per line (comments with #). Every entry MUST be exercised by the
# parity harness: the harness asserts the divergence STILL EXISTS. If the
# engine ever converges with the firmware on one of these, the test fails
# with a stale-allowlist message — remove the entry and promote the check to
# an equality check. An UNTAGGED failing check is a NEW divergence (hard
# failure: triage it — port the firmware behaviour or document it here).
#
# W8 (2026-08-18) converged FOUR former divergences into firmware-faithful
# behaviour, each now an equality check in the harness: wrap-around key
# zones (item 1), arp/seq phrase restart while the transport is stopped
# (item 2), polyphonic aftertouch (item 3), and multicast note routing
# (item 4). One deliberate divergence remains:

# The firmware's note-sequence decode returns the programmed velocity
# verbatim (a gated step with velocity byte 0 plays at velocity 0 = silent);
# Parvati's Sequencer::noteStep substitutes 100 for a 0 velocity so an
# untouched default step is audible. Deliberate UX deviation.
velocity-zero-substitution

# The firmware latches the mix-section gains (osc_1/osc_2 crossfade + the
# mix-op wet/dry pair) once per 40-sample block (voicecard/voice.cc:441-442)
# and relies on the analog mixer stage to smooth the DAC steps in hardware.
# The digital port has no analog domain, so a mix_balance / mix_parameter
# tick steps the gains by up to 16/255 of the instantaneous waveform — the
# audible zipper parvati_synth_drag_probe measured at 0.0597 vs its 0.05
# gate. Parvati glides the gains linearly across each block (~0.9 ms slew,
# 8.8 fixed-point accumulators in dsp::Voice), emulating the analog
# smoothing. STATIC CVs render byte-identically to the firmware (first
# block snaps; a steady CV has a zero increment; the glide converges to the
# exact firmware targets within one block of a change) — pinned block-by-
# block by the voicecard audio oracle in firmware_parity_test (scenario
# [10]), which asserts both the equality phases and THIS divergence on the
# balance-tick block. Audio-path divergence, sanctioned 2026-08-22.
mix-gain-glide
